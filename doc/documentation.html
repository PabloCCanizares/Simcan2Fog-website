Example Configuration

View on GitHub →

To define a basic smart home scenario in your simulation, modify the omnetpp.ini file as follows. This setup enables IoT sensors, fog nodes, and cloud data center integration.

showcases/iot/omnetpp.ini 
# Smart Home Configuration
*.controller.numWlanInterfaces = 1
*.controller.energyStorage.typename = "IdealEpEnergyStorage"

# Sensor Configuration
*.sensor*.model.controllerInterface = "wlan0"
*.sensor*.model.controllerPath = "^.^.controller"

# Fog Node Parameters
*.fogNode[*].computationPower = 2000 # MIPS
*.fogNode[*].memory = 16GB

# Network Settings
**.arp.typename = "GlobalArp"

Key Concepts

🏗️ Four-Layer Architecture

Simcan2Fog implements a hierarchical four-layer architecture:

  • IoT Layer: Sensors, actuators, controllers and edge users (see IoT Showcase)
  • Fog Layer: Interconnected fog nodes with routing and virtualization
  • Cloud Provider Layer: Resource orchestration and VM placement policies (see Data Centre Showcase)
  • Data Centre Layer: Compute and storage nodes with hypervisors

🌫️ Fog Nodes

Fog nodes are compute-capable devices positioned between IoT devices and cloud data centers. They provide:

  • • Local processing to reduce latency
  • • Resource management and virtualization
  • • Dynamic task offloading decisions
  • • Mesh networking capabilities using DNS for service discovery

📨 Message Queue & DNS

Simcan2Fog includes infrastructure services for seamless communication across all layers of the architecture:

  • Message Queue: Topic-based publish/subscribe infrastructure inspired by RabbitMQ and MQTT (used in Data Centre Showcase)
  • DNS: Hierarchical name resolution supporting A, CNAME, NS, and MX records (RFC 1034/1035 compliant)

See these concepts in action: IoT Showcase demonstrates sensor-actuator patterns with IoT devices, while the Data Centre Showcase shows VM provisioning with the message queue.

Frequently Asked Questions

Common questions about Simcan2Fog installation, usage, and features.

What is Simcan2Fog? ▼
Simcan2Fog is an open-source discrete-event simulation framework for modeling fog, edge, and cloud computing environments. It extends OMNeT++ and INET with fog-specific modules including hierarchical fog architectures, task offloading, DNS service discovery, and MQTT-style message queues.
What are the system requirements for Simcan2Fog? ▼
Simcan2Fog requires OMNeT++ 6.3.0 (or higher in the 6.x series) and INET 4.5.4. It runs on Linux, macOS, and Windows. You'll need a C++17-compatible compiler, at least 8 GB RAM, and 2 GB disk space for the complete installation.
How is Simcan2Fog different from iFogSim? ▼
Unlike iFogSim (CloudSim-based), Simcan2Fog is built on OMNeT++ and INET, providing full network stack simulation with realistic protocols (IEEE 802.15.4, WiFi, Ethernet, 5G). It includes native DNS service discovery, MQTT-style message queues, and supports both event-driven and GUI-based simulation workflows. See our detailed comparison table for more information.
How do I install Simcan2Fog? ▼
First, install OMNeT++ 6.3.0 and INET 4.5.4. Then clone the Simcan2Fog repository from GitHub, import it into the OMNeT++ IDE, and build the project. The complete step-by-step tutorial is available at our installation guide. Alternatively, try our Instant Simcan2Fog pre-configured VM for immediate use.
Where can I find example simulations? ▼
Simcan2Fog includes ready-to-run showcases in the showcases/ directory:
  • • Smart Home IoT - sensors, actuators, fog gateways
  • • Data Centre - VM provisioning, cloud integration
  • • Proxy & DNS - service discovery demonstration
  • • Statistics - result analysis examples
Each includes complete configuration files and documentation.
