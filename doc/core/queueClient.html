Queue Client

Bridge between nodes and the Message Queue

Overview

The QueueClient is a compound module that bridges any node (EdgeUser, CloudProvider, DataCentre) with the central Message Queue (SMQ). It handles the TCP transport, message wrapping, and the ACK-driven subscription protocol.

Compound Module Structure

┌──────────────────────────────────────────┐
│           QueueClient                    │
│                                          │
│  ┌────────────┐      ┌────────────┐      │
│  │ PushClient │      │ PullClient │      │
│  └──────┬─────┘      └──────┬─────┘      │
│         │                   │            │
│  ┌──────┴─────┐      ┌──────┴─────┐      │
│  │ pushSocket │      │ pullSocket │      │
│  │(TcpClient  │      │(TcpClient  │      │
│  │ SocketIo)  │      │ SocketIo)  │      │
│  └────────────┘      └────────────┘      │
│                                          │
│         ┌──────────────┐                 │
│         │      qt      │                 │
│         │ (MessageDisp.)│                 │
│         └──────────────┘                 │
└──────────────────────────────────────────┘

Submodules

PushClient (Outbound)

Sends messages to the SMQ on port 8444. Fire-and-forget delivery. Automatically sets the returnTopic via the autoSourceTopic flag. Wraps each SIMCAN_Message in an INET_AppMessage with a 20-byte header.

PullClient (Inbound)

Receives messages from the SMQ on port 8443. Uses an ACK-driven subscription loop: sends SM_QueueAck → receives one message → delivers to node → sends next ACK. This provides natural backpressure - the consumer controls the rate.

pushSocket / pullSocket (TcpClientSocketIo)

TCP transport adapters that handle connection establishment, data framing, and reconnection to the SMQ endpoints.

qt (MessageDispatcher)

Routes messages between the push/pull clients and the node's internal gates. Handles the multiplexing of inbound and outbound traffic.

Key Parameters

*.networkStack.queueClient.nodeTopic = "${fullName()}"
*.networkStack.queueClient.topic = "cloudProvider"
*.networkStack.queueClient.autoSourceTopic = true
*.networkStack.queueClient.pushSocket.connectAddress = "10.0.0.1"
*.networkStack.queueClient.pushSocket.connectPort = 8444
*.networkStack.queueClient.pullSocket.connectAddress = "10.0.0.1"
*.networkStack.queueClient.pullSocket.connectPort = 8443
