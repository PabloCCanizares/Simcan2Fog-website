AppProxy & ServiceTable

Application-layer gateway and service endpoint registry

AppProxy

The AppProxy is an application-layer gateway present inside every FogNode and DataCentre. It accepts TCP connections on port 443, extracts service names from RestfulRequest host headers, queries the ServiceTable, and routes traffic to the appropriate backend.

PASSTHROUGH (Client side)

Incoming TCP connections from external clients, accepted on port 443. Each new client connection spawns a Session and triggers service-name resolution. This is the proxy's client-facing side.

EDGE (Server side)

The proxy's outgoing connection to a local backend service endpoint (a blade application), opened after the ServiceTable lookup selects an instance and registered when that service calls registerService. This is the proxy's server-facing side.

Session Lifecycle

1

INIT

TCP connection accepted on port 443. Waiting for first request to determine target service.

2

PENDING

Service name extracted from host header. ServiceTable queried via selectIp(). Backend TCP connection being established.

3

ESTABLISHED

Backend connected. Bidirectional data flow between client and backend through the proxy.

Request Routing — End to End

ServiceTable

The ServiceTable is a passive module with no gates - it exposes only a C++ API. It maintains a map of service names to vectors of ServiceEntry (IP + port packed in a 64-bit value).

Registration

Services register via ProxyServiceRequest(REGISTER). Each registration adds an IP:port entry to the service name's endpoint list.

Load Balancing via selectIp()

When multiple endpoints exist, selectIp() performs uniform random selection across available entries. No TTL or expiry - entries persist until explicitly unregistered.

Domain Suffix Stripping

Incoming service names have the configured domain suffix (default: "localdomain") stripped before lookup. This allows both myservice and myservice.localdomain to resolve to the same endpoints.

DNS vs ServiceTable

Aspect DNS ServiceTable
LayerNetworkApplication
ResolvesDomains → IP addressesService names → IP:port endpoints
ProtocolUDP (standard DNS)C++ API (no network traffic)
ScopeGlobal (across network)Local (per node)
TTLYes (record expiry)No (persistent entries)

Key Parameters

# AppProxy
*.node.proxy.localPort = 443
*.node.proxy.serviceTablePath = "^.serviceTable"

# ServiceTable
*.node.serviceTable.domain = "localdomain"
