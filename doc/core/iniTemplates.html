INI Templates

Copy-paste omnetpp.ini starting points

Layer with config inheritance

A [General] section holds everything shared; named [Config X] sections extends it and override only what differs. Keep configs DRY — change one dimension per variant so comparisons stay apples-to-apples.

Minimal single datacentre

omnetpp.ini
[General]
network = SimpleCloudNetwork
sim-time-limit = 1h

# Central services
**.smqIp = "10.0.0.1"
**.dns   = "10.0.0.2"
**.ipv4.arp.typename = "GlobalArp"   # skip ARP for speed

# Data engine (JSON-backed app/VM templates)
*.simData.engine.apps = readJSON("database/apps.json")
*.simData.engine.vms  = readJSON("database/vms.json")

# One datacentre — 20 × 16 cores
*.dc.numBlades = 20
*.dc.zone      = "cloud"
*.dc.blade[*].numCpuCores = 16
*.dc.blade[*].memorySize  = 64GB
*.dc.blade[*].diskSize    = 2000GB
*.dc.blade[*].maxVMs      = 16

# Scalars only (no time-series)
**.scalar-recording = true
**.vector-recording = false

Fog–cloud hybrid (with variants)

Three tiers and three placement variants from one base — the canonical edge-vs-cloud comparison.

omnetpp.ini
[General]
network = FogCloudNetwork

# Cloud tier — abundant
*.dc.numBlades = 50
*.dc.zone      = "cloud"
*.dc.blade[*].numCpuCores = 32

# Fog tier — constrained, three edge zones
*.fog[*].numBlades = 5
*.fog[0].zone = "edge-west"
*.fog[1].zone = "edge-east"
*.fog[*].blade[*].numCpuCores = 8
*.fog[*].blade[*].memorySize  = 16GB

# Inter-tier latency (XML delayers)
*.backbone.ipv4Delayer.config = xmldoc("network/backbone.xml")

[Config EdgeOnly]
extends = General
*.user[*].deploymentZone = "edge-west"
*.dc.numBlades = 0

[Config CloudOnly]
extends = General
*.user[*].deploymentZone = "cloud"
*.fog[*].numBlades = 0

[Config HybridAdaptive]
extends = General
*.user[*].deploymentZone = ""   # let placement decide

Recording & parameter sweeps

selective recording
# off by default, opt in
**.statistic-recording = false
**.vector-recording    = false
**.scalar-recording    = true

# just what you study
**.allocatedCores.vector-recording = true
**.roundTripTime.vector-recording  = true

# sequence diagrams
record-eventlog = true
eventlog-message-detail-pattern = *:operation,result,vmId
parameter sweep
# iteration variables
*.numBlades            = ${B=10,20,40,80}
*.blade[*].numCpuCores = ${C=8,16,32}

# organise output per combo
output-scalar-file = results/B${B}-C${C}.sca

# repeat for significance
repeat   = 10
seed-set = ${repetition}
# → 4 × 3 × 10 = 120 runs

⚡ For large runs, record only last values and disable record-eventlog — it's the single biggest speed-up (10–100×).

More patterns

Multi-zone cloud
