What is Simcan2Fog?

Simcan2Fog is an open-source discrete-event simulation framework designed for modeling and analyzing Fog, Edge and Cloud computing environments, with particular focus on IoT and distributed applications.

It extends OMNeT++ and INET with high-level models for hierarchical fog architectures, task offloading, resource management, service orchestration and realistic network behavior in multi-tier systems.

Key Features

Native Fog & Edge Modeling

Hierarchical nodes, micro data-centers, multi-tier fog-cloud architectures

Full INET Network Stack

Wired & wireless, mobility, 5G/6G abstractions, SDN support

Task Offloading & Orchestration

Dynamic placement, container/VM simulation, orchestration policies

Detailed Performance Metrics

Latency, resource usage, energy, QoS, service response time

OMNeT++ GUI Support

Interactive visualization and debugging of complex fog scenarios

Modular & Extensible

GPL-3.0 • Easy to implement new fog strategies, devices and algorithms

How does it work?

Simcan2Fog provides high-level compound modules that represent fog devices, cloud servers, IoT sensors/actuators and the underlying communication infrastructure.

It allows realistic simulation of task offloading decisions, service migration, resource contention and end-to-end communication delays in hierarchical fog-cloud environments.
