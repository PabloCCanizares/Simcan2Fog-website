Features

The open source discrete-event simulation platform for fog, edge and cloud computing

🏗️ Core Framework 📡 Networking 🌫️ IoT & Fog ☁️ Cloud & Infrastructure 📊 Performance & Tools
🏗️

Core Framework

100% Open Source

Based on GPL-3.0 license offering unrestricted extensibility and modification for research and commercial use.

Built on OMNeT++ & INET

Leverages OMNeT++ 6.3.0 and INET 4.5.4 – widely adopted frameworks for discrete-event simulation and network protocol modelling.

Modular Architecture

Features modular and extensible architecture with clearly defined APIs enabling easy implementation of custom fog strategies and algorithms.

Flexible Configuration

Configure through NED language and INI files or interactively via graphical editor for rapid prototyping and experimentation.

📡

Networking & Communication

Detailed Network Models

Provides highly detailed communication network models including topology management, collision detection, TCP/UDP protocols, and traffic control through INET.

DNS Service Discovery

Implements DNS-based service discovery (RFC 1034/1035 compliant) supporting A, CNAME, NS, and MX records.

Message Queue Infrastructure

Features a message queue infrastructure inspired by RabbitMQ and MQTT for topic-based pub/sub communication.

Wireless & Wired Support

Supports both Wi-Fi (IEEE 802.11) and wired networking, with flexibility to integrate alternative radio stacks like IEEE 802.15.4 (ZigBee).

Network Latency Modelling

Supports network latency modelling with configurable delay distributions (truncated normal, uniform) for local, MAN, and backbone segments.

🌫️

IoT & Fog Computing

Hierarchical Fog Architectures

Supports hierarchical fog architectures with multiple fog tiers, edge devices, and geographically distributed data centres.

Comprehensive IoT Device Modelling

Includes comprehensive IoT device modelling – sensors, actuators, controllers with configurable measurement periods and units.

Realistic IoT Scenarios

Can simulate realistic IoT scenarios including smart homes, smart farming, smart cities, and industrial IoT deployments with hundreds of devices.

Dynamic Task Offloading

Supports dynamic task offloading and orchestration with configurable placement policies (first-fit, best-fit, zone-aware) and automatic fog-to-cloud escalation.

Ready-to-Run Showcases

Includes ready-to-run showcases demonstrating smart home environments, IoT deployments, data centre configurations, and fog node meshes.

☁️

Cloud & Infrastructure

Cloud Computing Capabilities

Inherits cloud computing capabilities from Simcan2Cloud including VM/container simulation, data centre operations, and SLA management.

Detailed Hardware Specifications

Models detailed hardware specifications at component level – CPU cores, frequency, scheduler types, MIPS, memory capacity, storage, and I/O throughput.

📊

Performance & Tools

Comprehensive Metrics

Provides comprehensive performance metrics including end-to-end latency, resource utilisation, energy consumption, QoS parameters, and service response times.

Rich Graphical Interface

Includes a rich GUI with interactive topology editor, real-time network visualisation, and integrated debugging tools through OMNeT++ IDE.

Detailed Statistics

Generates detailed simulation statistics with automatic recording of vectors and scalars, exportable to CSV/JSON for external analysis tools.

Efficient Resource Usage

Can run simulations on a single workstation with moderate resource usage (under 1 GB RAM for 100+ devices) or scale to larger environments.

Stable Performance

Maintains stable performance with approximately 3.1–3.35 × 10⁵ events/s throughput for medium to large-scale scenarios.

Peer-Reviewed & Validated

Validated through peer-reviewed publication in SoftwareX (2025) with reproducible results available via Zenodo.

Comprehensive Documentation

Supported by comprehensive documentation including NED reference, installation guides, configuration examples, and API documentation.

Active Community

Backed by a growing international research community with active development, support channels, and contributions via GitHub.
