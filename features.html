Features

The open source discrete-event simulation platform for fog, edge and cloud computing

•

Based on 100% open source software (GPL-3.0 license) offering unrestricted extensibility and modification

•

Built on OMNeT++ 6.3.0 and INET 4.5.4 – widely adopted frameworks for discrete-event simulation and network protocol modelling, respectively

•

Provides highly detailed communication network models including topology management, collision detection, transport protocols (TCP/UDP), and traffic control mechanisms through INET integration

•

Supports hierarchical fog architectures with multiple fog tiers, edge devices, and geographically distributed data centres

•

Includes comprehensive IoT device modelling – sensors, actuators, controllers with configurable measurement periods, values, and units

•

Implements DNS-based service discovery with hierarchical resolution (RFC 1034/1035 compliant) supporting A, CNAME, NS, and MX record types

•

Features a message queue infrastructure inspired by RabbitMQ and MQTT, enabling topic-based publish/subscribe communication across all fog layers

•

Inherits cloud computing capabilities from Simcan2Cloud including virtualisation (VM/container simulation), data centre operations, SLA management, and cloud provider orchestration policies

•

Models detailed hardware specifications at the component level – CPU cores, core frequency, scheduler types, MIPS, memory capacity, storage size, and I/O throughput

•

Supports dynamic task offloading and orchestration with configurable placement policies (first-fit, best-fit, zone-aware) and automatic fog-to-cloud escalation

•

Provides comprehensive performance metrics including end-to-end latency, resource utilisation, energy consumption, QoS parameters, and service response times

•

Includes a rich graphical user interface (GUI) with interactive topology editor, real-time network visualisation, and integrated debugging tools through OMNeT++ IDE

•

Can simulate realistic IoT scenarios including smart homes, smart farming, smart cities, and industrial IoT deployments with hundreds of devices

•

Supports network latency modelling with configurable delay distributions (truncated normal, uniform) for local, MAN, and backbone network segments

•

Features modular and extensible architecture with clearly defined APIs enabling easy implementation of custom fog strategies, devices, and algorithms

•

Allows configuration through NED language and INI files or interactively via graphical editor for rapid prototyping and experimentation

•

Generates detailed simulation statistics with automatic recording of vectors and scalars, exportable to CSV/JSON for external analysis tools

•

Can run simulations on a single workstation with moderate resource usage (under 1 GB RAM for 100+ devices) or scale to larger environments

•

Maintains stable performance with approximately 3.1–3.35 × 10⁵ events/s throughput for medium to large-scale scenarios

•

Supports both wireless (Wi-Fi, IEEE 802.11) and wired networking, with the flexibility to integrate alternative radio stacks like IEEE 802.15.4 (ZigBee)

•

Includes ready-to-run showcases demonstrating smart home environments, IoT deployments, data centre configurations, and fog node meshes

•

Validated through peer-reviewed publication in SoftwareX (2025) with reproducible results available via Zenodo

•

Supported by comprehensive documentation including NED reference, installation guides, configuration examples, and API documentation

•

Backed by a growing international research community with active development, support channels, and contributions via GitHub
