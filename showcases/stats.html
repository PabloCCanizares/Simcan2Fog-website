Statistics Showcase

Eventlog Recording & Statistical Capture

Overview

The Statistics showcase demonstrates how to configure eventlog recording and statistical capture in Simcan2Fog simulations. It uses a simple IoT scenario to teach the core pattern: disable globally, enable selectively.

Key Concept: Disable Globally, Enable Selectively

OMNeT++ generates enormous amounts of data by default. The correct approach is to disable all recording globally, then selectively enable only the modules and signals you need. This keeps result files manageable and simulations fast.

Eventlog Recording

Captures module-level events for sequence chart generation. Enabled per-module to track message exchanges between specific components.

Statistical Recording

Captures scalar values, vector time series, and histograms. Enabled per-module to record specific signals like powerState from actuators.

Network Topology

The showcase uses the IotStatistics network - a simple IoT scenario with all wireless communication via IEEE 802.15.4.

The Recording Pattern

Both eventlog and statistical recording follow the same three-step pattern:

1

Enable Globally (Temporary)

First, turn on recording at the broadest scope so all descendant modules inherit the setting.

2

Enable Selectively

Enable recording only for the specific modules you want to capture. These more specific patterns take precedence.

3

Disable Everything Else

Disable recording at the wildcard level. Because OMNeT++ applies the most specific match, the selective enables from step 2 survive while everything else is turned off.

Eventlog Configuration

Eventlog recording captures message send/receive events for generating sequence charts in the OMNeT++ IDE.

omnetpp.ini - Eventlog 
# Step 1: Enable globally
record-eventlog = true

# Step 2: Enable for specific modules
**.lamp1.**.module-eventlog-recording = true
**.controller.**.module-eventlog-recording = true
**.sensor1.**.module-eventlog-recording = true

# Step 3: Disable everything else
**.module-eventlog-recording = false

Pattern specificity: **.lamp1.** is more specific than **, so the lamp1 enable survives the global disable. The result is eventlog data only for lamp1, controller, and sensor1.

Statistical Recording

Statistical recording captures scalar summaries, vector time series, and histogram bins. The showcase captures the powerState signal from lamp1.model (IotActuatorModel) as a vector.

omnetpp.ini - Statistics 
# Enable for lamp1.model and all its statistics
**.lamp1.model.*.statistic-recording = true
**.lamp1.model.*.scalar-recording = true
**.lamp1.model.*.vector-recording = true

# Disable everything else
**.statistic-recording = false
**.scalar-recording = false
**.vector-recording = false
**.bin-recording = false

Scalar Recording

Summary values written to .sca files (min, max, mean, count)

Vector Recording

Time series data written to .vec files (timestamp + value pairs)

Bin Recording

Histogram bins for distribution analysis (disabled here to save space)

Analysis File

The showcase includes an analysis file Iot_Statistics.anf that points to the result files for visualization in the OMNeT++ IDE.

Result Files

  • • results/Iot_Statistics-*.vec - Vector time series data (powerState over time)
  • • results/Iot_Statistics-*.sca - Scalar summary statistics

Deterministic Seeds: The showcase uses fixed seeds (seed-set=0, seed-0-mt=0) for reproducible results. Every run produces identical output, making it suitable for regression testing and result comparison.

Full Configuration

showcases/Statistics/omnetpp.ini 
# Network Configuration
network = IotStatistics
sim-time-limit = 15min

# Deterministic seeds
seed-set = 0
seed-0-mt = 0

# --- Eventlog Recording ---
record-eventlog = true
**.lamp1.**.module-eventlog-recording = true
**.controller.**.module-eventlog-recording = true
**.sensor1.**.module-eventlog-recording = true
**.module-eventlog-recording = false

# --- Statistical Recording ---
**.lamp1.model.*.statistic-recording = true
**.lamp1.model.*.scalar-recording = true
**.lamp1.model.*.vector-recording = true
**.statistic-recording = false
**.scalar-recording = false
**.vector-recording = false
**.bin-recording = false
🔍

What to Observe During Execution

After running the simulation, verify these outputs:

  • • The .elog file contains events only for lamp1, controller, and sensor1
  • • Open the .elog in the Sequence Chart view to see message exchanges
  • • The .vec file contains only powerState vector data from lamp1.model
  • • Open Iot_Statistics.anf to visualize the powerState time series
  • • Re-running with the same seeds produces identical results
