Why Choose Simcan2Fog?

🌐

True Network Simulation

Built on INET 4.5.4, Simcan2Fog provides realistic TCP/UDP stack, collision detection, MAC protocols, and traffic control – not simplified abstractions.

🔧

Full-Stack IoT Support

Complete IoT ecosystem with sensors, actuators, controllers, DNS service discovery, and MQTT-style message queuing – unique among fog simulators.

👁️

Visual Debugging

OMNeT++ GUI provides real-time network visualization, packet inspection, and interactive debugging – invaluable for understanding complex scenarios.

📖

Active & Peer-Reviewed

Published in SoftwareX (2025), actively maintained, with comprehensive NED documentation and reproducible research artifacts on Zenodo.

⚡

Cloud Integration

Inherits Simcan2Cloud capabilities for data center simulation, VM orchestration, and SLA management – seamless fog-to-cloud integration.

🎯

Extensible Architecture

Modular design with clear APIs makes it easy to implement custom fog strategies, devices, and algorithms without touching core code.
