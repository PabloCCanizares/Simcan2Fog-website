Tutorial

Learn how to set up Simcan2Fog

Below, we give a brief tutorial-style introduction on how to get started with installing and using Simcan2Fog. For other tutorial-style introductions on how to use Simcan2Fog as well as more in-depth information, please refer to the publications page.

The easy way

For quickly trying out Simcan2Fog and for running Simcan2Fog on systems you do not have administrative access to, we are recommending Instant Simcan2Fog, a virtual machine that contains a ready-to-run version of Simcan2Fog and all supporting tools.

About Instant Simcan2Fog →

If you are using Instant Simcan2Fog, you can directly skip ahead to the final step: running Simcan2Fog.

For learning how to set up Simcan2Fog on your own machine, read on.

The hard way

📝 Note:

Simcan2Fog runs on Linux, Mac OS X, and Windows. Because of the extensive debugging capabilities that it offers, Simcan2Fog is best built and run on Linux. For running Linux on Windows, we recommend using the Windows Subsystem for Linux (WSL) or a virtual machine running Linux. This will allow the use of additional libraries and result in a much smoother experience than running Simcan2Fog natively on Windows.

This tutorial assumes that you are using Ubuntu Linux, that your home directory is /home/user, and that all necessary software will be installed in /home/user/omnetpp-6.3.0.

Aside from the paths given, these steps are similar when building and running the simulations on Mac OS X or Windows (using WSL).

1 Download and build OMNeT++ 6.3.0

Download OMNeT++ 6.3.0 and unpack it as /home/user/omnetpp-6.3.0.

📝 Note:

If you unpack OMNeT++ to a different folder, make sure it contains no spaces.

On Linux and Mac, the OMNeT++ install guide has many helpful hints on pre- and post-configuration of your system.

Build OMNeT++ 6.3.0 by running:

cd ~/omnetpp-6.3.0
./configure

(making sure to examine the summary for potential errors) followed by 

make

to start the build process. If all went well, this will result in /home/user/omnetpp-6.3.0/bin/omnetpp being built. Run 

omnetpp

to launch the OMNeT++ 6.3.0 IDE. This tutorial will assume that you picked /home/user/omnetpp-6.3.0/samples as your workspace.

2 Download and build INET4 4.5.4

The easiest way to install INET4 is from the OMNeT++ IDE wizard:

  1. In the OMNeT++ IDE, go to Help → Install Simulation Models
  2. Click on INET Framework 4 and let the default path
  3. Click Install Project

After the installation is complete, you can run a tutorial, example or showcase provided by INET to verify that everything is working correctly.

3 Download and build the Simcan2Fog module framework

Download Simcan2Fog 1.2.0 and unpack it as /home/user/omnetpp-6.3.0/Simcan2Fog. Import the project into your OMNeT++ IDE workspace by clicking File → Import → General: Existing Projects into Workspace and selecting the directory you unpacked the module framework to.

Build the newly imported project by choosing Project → Build All in the OMNeT++ IDE. After the project built, you are ready to run your first fog computing simulations.

Configure environment variables:

Add the following lines to your ~/.bashrc (or shell equivalent): 

# Load OMNeT++, INET4, and Simcan2Fog environment variables
[ -f "$HOME/omnetpp-6.3.0/setenv" ] && source "$HOME/omnetpp-6.3.0/setenv" -q
[ -f "$HOME/omnetpp-6.3.0/inet4.5/setenv" ] && source "$HOME/omnetpp-6.3.0/inet4.5/setenv" -q
[ -f "$HOME/omnetpp-6.3.0/Simcan2Fog/setenv" ] && source "$HOME/omnetpp-6.3.0/Simcan2Fog/setenv" -q

Then reload your shell configuration by running source ~/.bashrc.

✓ Final step: Run the Simcan2Fog demo scenario

In the OMNeT++ IDE, simulate the Simcan2Fog smart home demo scenario by right-clicking on Simcan2Fog/showcases/iot/omnetpp.ini and choosing Run As → OMNeT++ simulation.

Similar to the last example, this should create and start a launch configuration. You can later re-launch this configuration by clicking the green Run button in the OMNeT++ IDE.

If everything worked as intended, this will give you a working simulation scenario using OMNeT++ and INET running in parallel to simulate a smart home environment with sensors, actuators, and fog nodes processing IoT data.

Understanding the simulation:

If you ran a debug build of the simulation (e.g., by choosing Debug as instead of Run as when launching the simulation), you will see a wealth of debug output in the log window. Note, however, that a simulation running in debug mode executes at lower speed.

The smart home scenario demonstrates how sensors collect data (brightness, temperature), controllers process the information locally, and fog nodes provide additional computational capacity when needed. The simulation shows the interaction between IoT devices, fog layer, and cloud data centres, allowing you to measure latency and resource usage metrics.

Available Showcases:

🏢 Datacentre

Shows how users request cloud VMs, deploy services, and how local applications communicate with cloud services.

🏠 IoT (Smart Home)

Quick configuration and topology for IoT models. Models a complete smart house with sensors, actuators, and controllers.

🔗 Proxy

Explores the Proxy module, a key component of the framework. Includes optional DNS integration.

📊 Statistics

Demonstrates how to configure simulations for statistical and event capture. Generate sequence charts to visualize interactions.

New Projects

While we recommend simply modifying the tutorial simulation to get started with using Simcan2Fog, pretty soon you might want to create a dedicated OMNeT++ project.

To create a new Simcan2Fog project:

  1. In the OMNeT++ IDE, go to File → New → OMNeT++ Project
  2. Name your project and select the workspace location
  3. Right-click on your project → Properties → Project References
  4. Check both inet4.5 and Simcan2Fog
  5. Click Apply and Close

Your new project can now use all the modules and functionality provided by Simcan2Fog and INET4.

End
